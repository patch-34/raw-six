# Raw Six

[English](README.md) · **Русский**

Шестиголосный генератор сигнала в формате JSFX. Для каждого голоса доступны независимые параметры формы сигнала, частоты и уровня.

## Описание и параметры

- Шесть независимых голосов.
- Формы сигналов: **Sine**, **Tri**, **Square**, **Saw**, **Noise**.
- Диапазон частот: от 20 до 7000 Гц, предусмотрено квантование по полутонам.
- Сглаживание изменений частоты и громкости.
- Автоматическая нормализация по числу активных голосов.
- Выходной сигнал поступает в левый и правый каналы.

## Управление

| Параметр | Назначение |
| --- | --- |
| **Output** | Включение и отключение выхода. |
| **Master** | Общая громкость. |
| **Quantize** | Квантование по полутонам. |
| **Waveform 01–06** | Форма сигнала соответствующего голоса. |
| **Freq** | Частота голоса. |
| **Vol** | Уровень голоса. |

## Запись результата

Установите для трека режим **Record: output** вместо записи входа. В состав пакета входит шаблон трека `Patch34_Raw_Six.RTrackTemplate`, где этот режим уже настроен.

## Установка

### Через ReaPack

Добавьте [каталог Patch34 ReaPack](https://raw.githubusercontent.com/patch-34/patch34-reapack/main/index.xml) через **Extensions → ReaPack → Import repositories…** и установите пакет **Raw Six** из **Browse packages**. Вместе с эффектом устанавливается шаблон трека.

### Вручную

Скопируйте `Patch34_Raw_Six.jsfx` в папку `Effects` ресурсов REAPER, а файл `Patch34_Raw_Six.RTrackTemplate` — в `TrackTemplates`. Повторно просканируйте JSFX в настройках REAPER при необходимости.
