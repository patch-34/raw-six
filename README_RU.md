# Raw Six

[English](README.md) · **Русский**

Шестиголосный генератор сигнала для REAPER в формате JSFX.

## Описание

Raw Six — генератор с шестью независимыми голосами, реализованный как JSFX-эффект для REAPER.

Предназначен для следующих задач:

- Процедурный саунд-дизайн.
- Создание текстур и длительных фоновых тонов (дронов).
- Генерация тональных шумовых слоёв.
- Экспериментальный синтез звука.

Эффект не требует дополнительных инструментов и позволяет записывать генерируемый сигнал непосредственно в аудио внутри REAPER.

## Возможности

- 6 независимых голосов.
- Формы сигнала: Sine, Triangle, Square, Saw, Noise.
- Диапазон частот 20–7000 Гц с логарифмической шкалой.
- Дополнительное квантование частоты по полутонам.
- Плавная автоматизация высоты тона.
- Сглаживание изменения громкости для предотвращения щелчков.
- Автоматическая нормализация по числу активных голосов.
- Плавное нарастание сигнала после включения выхода.
- Стереовыход с одинаковым сигналом в левом и правом каналах.
- Низкая нагрузка на процессор.

## Схема прохождения сигнала

Форма волны → (дополнительная обработка шума) → сглаживание громкости → суммирование голосов → автоматическая нормализация → мастер-уровень → плавное включение выхода → выход.

## Элементы управления

### Общие

- **Output** — включение выхода (**On**) или заглушение (**Muted**).
- **Master** — общая громкость (0–127).
- **Quantize** — квантование частоты: выключено (**Off**) или по полутонам (**Semitone**, 12-TET).

### Для каждого голоса (01–06)

- **Waveform** — форма сигнала: Sine / Tri / Square / Saw / Noise.
- **Freq** — основная частота (20–7000 Гц, логарифмическая шкала).
- **Vol** — громкость голоса (0–127, со сглаживанием).

## Настройка записи

По умолчанию REAPER записывает входящий сигнал (**Input**), а не выход цепочки эффектов (**FX output**).

### Вручную

1. Включите запись на треке (**Arm**).
2. Нажмите правой кнопкой мыши на кнопку записи трека.
3. Выберите **Record: output**.
4. Установите запись в стерео или моно.

### Шаблон трека

В комплект входит шаблон `Patch34_Raw_Six.RTrackTemplate`. В нём режим **Record: output** уже установлен.

## Установка

### Через ReaPack

Добавьте [каталог Patch34 ReaPack](https://raw.githubusercontent.com/patch-34/patch34-reapack/main/index.xml) через **Extensions → ReaPack → Import repositories…**, найдите **Raw Six** в **Extensions → ReaPack → Browse packages** и установите пакет. Шаблон трека устанавливается вместе с эффектом.

### Вручную

Скопируйте `Patch34_Raw_Six.jsfx` в каталог `Effects` ресурсов REAPER:

- macOS: `~/Library/Application Support/REAPER/Effects/`
- Windows: `%APPDATA%\REAPER\Effects\`
- Linux: `~/.config/REAPER/Effects/`

Чтобы установить шаблон трека вручную, скопируйте `Patch34_Raw_Six.RTrackTemplate` в каталог `TrackTemplates` ресурсов REAPER.

Затем выполните повторное сканирование JSFX через **Options → Preferences → Plug-ins → ReaScript / JS → Re-scan**.

Название эффекта в REAPER: **JS: Raw Six**.

## Порядок работы

1. Добавьте генератор на трек.
2. Установите **Record: output**.
3. Включите запись на треке (**Arm**).
4. Запишите звук.
5. Измените параметры и повторите запись при необходимости.
